
# GearGo – Intelligent Vehicle and Travel Rental Platform

## 📌 About the Project

GearGo is a full-stack vehicle and travel rental platform that connects customers with local rental vendors. It enables users to explore, compare and book vehicles and travel equipment based on location and availability.

The platform also provides opportunities for local vendors to list their rental items and reach more customers.

## ✨ Key Features

- User Registration and Authentication
- Customer and Vendor Accounts
- Vehicle Rental Listings
- Travel Equipment Rentals
- Location-Based Rental Discovery
- Rental Availability Management
- Booking Management
- Vendor Dashboard
- Trip Bundle Builder

## 🛠️ Tech Stack

- Frontend: React.js
- Backend: Python, Django REST Framework
- Database: MySQL
- API: REST API

## 📦 Main Modules

1. Authentication
2. Account Management
3. Rental Listings
4. Vehicle Management
5. Travel Equipment Management
6. Location-Based Discovery
7. Booking Management
8. Vendor Dashboard
9. Trip Bundle Builder

## 🎯 Objective

To simplify vehicle and travel equipment rentals while supporting local rental businesses through a digital marketplace.
